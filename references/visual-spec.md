# 视觉规范（可直接照抄的参数）

## 1. 分辨率

| 逻辑画布 | 放大 | 成片 | 适用 |
|---|---|---|---|
| 480×270 | ×4 | 1920×1080 | 默认，颗粒感最强，渲染最快 |
| 640×360 | ×3 | 1920×1080 | 需要多一点细节（人物多、场景复杂） |
| 960×540 | ×2 | 1920×1080 | 接近"高清像素"，代价是渲染时间 ×3 |

铁律：**1920 必须被逻辑宽整除**，放大只用 NEAREST。

封面单独做：382×239 ×3 = 1146×717（B 站 16:10）。

## 2. 色板

- 只允许三个主档：**主色（纸白/深底）、强调色、黑**。再加 3–4 个中间阶（墙裙、投影、玻璃、覆羽带）。
- 强调色全片配额：**每 30 秒不超过 5 次实体出现**（心、章、灯、血），其余只做光。
- 抽色来源优先级：**原 MV 逐帧 > 官方曲绘 > 音频内嵌封面**。封面常是白底大字，抽出来的"最深色"可能是浅粉 —— 必须校验 `max-min ≥ 55` 且最深色亮度 < 90，否则用预设强调色。
- 白场 / 品红场 / 黑场三段结构（原 MV 语言）：
  - 白场＝现实（纸白墙 + 线稿 + 黑剪影）
  - 强调色场＝幻想 / 药 / 亲密（满色背景 + 白线 + 黑剪影）
  - 黑场＝闭眼之后（黑底 + 强调色轮廓 + 白笔刷）

## 3. 人物

单位制：**站姿 1 单位 = h/76，坐姿 1 单位 = h/60**（h = 头顶到脚底）。

站姿（背对）部件坐标（单位，原点=脚底中线，向上为正）：

| 部件 | 参数 |
|---|---|
| 裙 | 顶点 (−7.6,34) (7.6,34) (12,0.8) (6,−0.6) (0,−1.2) (−6,−0.6) (−12,0.8) |
| 腰 | ±6.2 @34 → ±7.9 @44 |
| 胸 | ±7.2 @53.6 → ±6.4 @44 |
| 圆肩 | 椭圆 中心 (0,55.6) rx9 ry2.6 |
| 颈 | ±2.3，y 54.6–61.6 |
| 头 | 椭圆 中心 (0,68) rx5.4 ry6.2 |
| 发束 | 从 (±3.9, 70.6) 到 (±5.3, 59) 锥形 r1.05→0.85 |
| 手臂 | (±8.4,54.4)→(±9.8,44) r2.4→2.1；(±9.8,44)→(±9.2,33.6) r2.1→1.8；手 椭圆 rx1.9 ry2.3 |
| 小腿 | (±3.9,6.2)→(±3.9,1.2) r3.1→2.7；脚 (±3.9,1.0)→(±5.6,0.2) |

要点：
- 头宽 ≈ 身高 14%，肩宽 ≈ 22%。头比肩宽一半略大即为"套娃"。
- 剪影靠**负空间**拆件：颈、肘、膝必须从轮廓里读得出来。
- 边缘光：把 mask 向左上偏移 1px 涂亮色，再压主体（不要做"描边贴纸"）。

坐姿（背对）：裙摊开（±17.5 @0 → ±11 @18）、腰 ±10 @18–34、背 ±8.6 @34–43、肩 ±11.2 @39.6、头 (0,52.6) rx5.4 ry6.2、肘外撇到 ±15.8 @24.6、膝从裙两侧顶出 椭圆 (±12.6,19.5) rx5.4 ry5.8。

**不做大特写**。全身/中景（人物占画面 1/5–1/3）是这个画幅唯一稳的构图。

## 4. 头顶（最容易翻车的地方）

```
crown_top(u) = 后发椭圆上缘 + 蓬松(1.15·s) + 起伏(0.55·s·sin)   # 分束轮廓：2–3 个峰 + 谷
bang_bot(u)  = 6 束各自下垂量，末端斜切参差
发缝          = 从发旋出发的贝塞尔曲线（2px），不要放射直线（会变蜘蛛网）
发旋          = 极坐标旋涡 r ∝ t^0.78, θ ∝ t^1.25，角度取朝头发内侧（96°–172° / 84°–8°）
```
- 后发椭圆必须**低于**分束谷，否则谷被填平 → 头顶变成锅盖。
- 头发垂直厚度至少要 8px 才装得下分缝，不够就先加高头顶（`_bry = hh + 3.2`）。
- 发尾：**上窄下宽散开**（不是收成一个尖），末端 3 段参差斜切。

## 5. 翅膀

```
翼形：lead 9 点（-t, -0.125·sin(πt·0.72)+0.02t²）+ trail 19 点（0.055+0.235·sin(π(1-t)·0.92)，隔点 +0.03 锯齿）
覆羽：3 排 arc(8°..172°)，半径 S·(0.055+0.028·row)，每排 7-row 个
前缘带：mask & ~roll(mask, 0.075S) → 覆羽带
```
- 填充实色（白场用白，色场用线稿），羽线用背景色 1px → 读成"玻璃上的翅膀"。
- 翅膀从窗框两侧长出（左右各一），不要从人物背上长（会被躯干裁掉一半）。
- 小尺寸（<60px）只画线稿，画实体一定糊成纸片。

## 6. 手

- 复用 `hand()`（五指张开）/ `fist()`（握拳：拳面 + 四指关节 + 横压拇指）。
- 手指可见宽度 ≥5px，否则被 1px 描边吃掉。
- 两只手交叠时，上面那只先垫一圈暗边，才分得清。

## 7. 房间陈设（一居室）

必须成对的"两种状态"：在场 / 只剩 1px 轮廓（第二幕的消失全靠这个）。
清单：窗（框 + 玻璃 + 中梃 + 窗台厚度）、床（被面起伏 + 枕头）、电视（机身 + 屏幕 + 扫描线）、
门（门框 + 门缝光）、桌（台面 + 投影）、墙裙（极浅线）、地面投影。

不要画：地板收敛线（480 宽下像裂纹）、通栏地平硬线（像舞台布景，用抖动过渡代替）。

## 8. 镜头语汇

| 手法 | 实现 | 用途 |
|---|---|---|
| 推近 | `zoom(a, 1+p·0.05, cx, cy)` | 情绪上涨 |
| 平移 | `shift(a, dx, dy)`（np.roll） | 手持漂移、横移 |
| 呼吸 | 人物 h × (1 ± 2–3%) | 所有静镜头的保底运动 |
| 光移 | 光带 offset = sin(t·0.4)·10 | 床/窗/桌面 |
| 扫描线 | `scan(a, t, speed, k)` | CRT / 电视 / 回忆 |
| 白闪 | `flash(a, k)`，k ≤ 0.35 | 只给关键拍 |
| 溶解 | `dissolve(a, b, k)` | 换场 |

每镜必须至少有一种；完工后跑 `audit`，0.2s 帧差 < 0.25% 的镜头要补运动。

## 9. 字幕

| 项 | 值 |
|---|---|
| 位置 | 居中，距底 150px（1080p） |
| 日文 | msgothic 40px |
| 中文 | msyh 30px，日文下方 +12px |
| 描边 | 2px（中文可 2px），颜色 = 深色场用黑、黑场用深强调色 |
| 底色 | **无**（本项目统一：无底框，只描边） |
| 颜色 | 白场品红 / 品红场白 / 黑场亮强调色 |
| 时长 | 与下一句的间隔取 min(next, +3.6s)；提前 0.15s 入 |
| 绘制时机 | 所有调色/暗角之后 |

## 10. 封面

- 尺寸 1146×717（16:10），原生长宽比绘制，**不要拉伸 16:9**。
- 元素 ≤4：一个大形状（光环/窗/雪球）+ 一个剪影 + 一行大字 + 一个小标签。
- 大字在放大层用真字体，带 3px 深色描边；字号 ≥ 画面宽 1/12。
- 缩略图测试：缩到 160px 宽，还能读出"一个人 + 一个形状 + 一行字"才算过。
