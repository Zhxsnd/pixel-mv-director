# 流水线（音源 + 歌词 → B 站成品）

每一步只写**要产出什么、判据是什么**，不写命令——用什么语言实现由执行者决定。
如果你手上已经有实现（本机参考实现见 SKILL.md 末节），把它当作这一步的加速器。

---

## 0. 收料

需要两样：**音源**（flac/mp3/wav）+ **歌词**（.lrc，带 `[mm:ss.xx]` 行标）。

- 先验音频内容（转写 20–60s 抽查），**文件名不可信**——曾遇到文件名叫 A、实际是 B 的情况。
- 缺歌词：可以先出纯器乐版；缺行标：必须先对齐（转写或手标），否则字幕全错。
- 读不到 ffprobe 时，用 `ffmpeg -i` 的输出解析 `Duration:`。

产出：`时长(秒)`、`歌词行表[(t, 原文)]`、`色板 7 个字段`。

## 1. 拆曲

1. 时长 → 帧数（`round(dur × fps)`）。
2. BPM：自相关取**第一个显著局部峰**（>0.35），再折叠到 70–180。取全局最大只会拿到小节周期。
3. 能量：0.5s 窗 RMS，归一化。
4. 分段：歌词间隔 > 4s 处切；段均值 > 中位数×1.12 判副歌，< ×0.78 判间奏。
5. 抽色：音频内嵌封面 → 量化取主色 → 映射成 7 个字段（无彩度就补预设强调色）。

产出：段落表（含色场）、色板。**这一步错了全片都错**，段标签必须人工看一遍。

## 2. 剧本与分镜（核心，不可省）

拆曲只告诉你"哪里是副歌"，不告诉你"拍什么"。

1. **研究原 MV**（有的话）：抽帧 → 接触表 → 测色与占比 → 拆幕 → 归纳画面语言与运镜。
2. **写剧本**：三个问题（在说什么 / 谁在看 / 最后发生什么）+ 五幕骨架 + 每幕一句 intent。
3. **落成 `script.json`**：一镜一条（t0/t1/act/shot/desc/motion/trans），边界对齐 LRC 行标。

详细方法见 `narrative.md`。

## 3. 定调（人工 3 分钟，不可省）

给每镜渲一张中段帧，拼成接触表，然后只看四件事：

- 白场段是否只有房间型镜头？强调色段是否只有色场型？
- 有没有"看不出在干嘛"的空镜？（只有几何形状 = 失败，要补上下文）
- 人物占比是否在 1/5–1/3？太大就缩小，太小就补光/推近。
- 是否只有一个强调色？

不满意改 `script.json` 的 `shot` 字段，或改镜头实现。

## 4. 校验（硬错误不渲）

7 项检查，前 5 条是硬错误：

| 检查 | 判据 |
|---|---|
| 空洞 | 相邻镜 gap > 0.2s |
| 重叠 | 后镜起点早于前镜终点 0.2s 以上 |
| 没铺满 | 最后一镜结束 < 音频时长 −0.3s |
| act 越界 | 引用不存在的幕 |
| 歌词无画 | 某句歌词的时间点不在任何镜头里 |
| 同镜连用 | 相邻两镜同一个镜头（警告） |
| 转场密度 | 切点 ≥12 却 0 转场，或转场 > 60% 切点（警告） |

## 5. 字幕

- 默认只显示 LRC 原文；要双语就补 `cn.txt`（一行一句，与 LRC 行数一致）。
- 中文 ≤22 字/行，否则 30px 会顶到画面两侧。
- 保留原句的语序怪味，不要雅化成广告语。
- 重复副歌可复用译文，但要核对 LRC 是否给了不同时间码。
- 版式与配色见 `engine-spec.md` §9。

## 6. 渲染

先出 30 秒（验节奏、字幕、色场），再出全片。

性能参考（480×270 逻辑 / 24fps / 1080p x264 crf18）：
- 30 秒 ≈ 60–90 秒
- 4 分钟 ≈ 3–5 分钟（6076 帧）

技术细节（管道、编码参数）见 `engine-spec.md` §10。

## 7. 验收

必须全绿：

| 检查 | 标准 | 不达标怎么办 |
|---|---|---|
| 分镜校验 | 0 硬错误 | 按报错逐条补镜/改时间 |
| 停住镜头 | 0 个（0.2s 帧差 < 0.25%） | 给该镜头加呼吸/漂移/光移 |
| 镜头多样性 | 同一镜头全片 ≤6 次，且不毗邻 | 扩候选池或加变体 |
| 色场 | 白/强调/黑三段都要有 | 调段落标签 |
| 时长 | 与音频差 < 0.1s | 编码时用 `-shortest` |
| 脏色 | 无青/黄异常块（占比 < 0.2%） | 查 `k>1` 的混合与切片连续性 |
| 字幕 | 每句都出现，无"歌：xxx" | 过滤 LRC 元信息 |
| 转场 | 已在换幕/跳时空处、同种不连用 | 重跑转场编排（择优规则） |

## 8. 发布包

- 封面 1146×717（16:10），元素 ≤4，大字 3px 描边。
- 标题 3 选、简介骨架（含章节）、标签 9 个以内。
- 按 `publish-bilibili.md` 补齐原作信息与版权声明后再投。

## 目录结构（每首歌一个工程目录）

```
歌曲名/
  audio.flac  lyrics.lrc  cn.txt
  script.json          # 剧本 + 分镜（唯一的故事来源，可手改）
  stills/              # 每镜中段一帧 + 接触表
  MV.mp4               # 成片
  cover_1146x717.png
  publish.txt  audit.txt
  shots_custom.*       # 这首歌专属的镜头（可选）
```

## 自动化边界（别指望的部分）

| 能自动 | 不能自动 |
|---|---|
| 时长 / BPM / 能量分段 / 抽色 | 剧本与主题（要靠读歌词） |
| 镜头排布 / 变体 / 色场 / 转场择优 | 造型设计（发型、服装、专属 motif） |
| 字幕排版 / 描边 / 配色 | 翻译质量 |
| 渲染 / 混流 / 封面 / 文案骨架 | 封面构图是否抓人 |
| 运动量与脏色审计 | "这一镜好不好看" |
