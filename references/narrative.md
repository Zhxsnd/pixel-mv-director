# 从歌到剧本（叙事链路）

固定链路：**查原曲 MV / 读歌词 → 写剧本 → 分镜脚本 → 成片**。
不做"套模板"（双线 A/B、信物、播放器 UI 那类是别人的模板，用一次就像抄的）；剧本必须从这首歌自己长出来。

---

## 一、材料：先看原 MV，再看歌词

### 有原 MV（优先）

1. **找到源**：B 站 / YouTube / Nico。确认是官方或授权转载，记下 av/BV 号与原始曲号（如 sm35933131）。
2. **拉 1080p，抽帧**：每 2 秒一帧，拼成接触表（contact sheet）。100 秒的片子大约 50 帧，一屏能看完。
3. **测色**（这一步决定全片美术）：
   ```
   ffmpeg -i MV.mp4 -vf "fps=1/2" ref/f_%03d.png
   ```
   对 6–8 张关键帧统计 RGB 直方图，记下：主色 / 强调色 / 黑，以及**各自占屏比例**。
   比例比色值更有信息：品红占 74–85% 说明这是"色场片"，不是"白底加一点红"。
4. **拆结构**：按能量与画面语言把片子切成幕，记时间和每幕的色场。
5. **归纳画面语言**（写成 3 条以内）：
   - 人物：剪影 / 线稿 / 有脸？（IMAWANOKIWA = 全片没有一次人脸特写）
   - 场景：写实房间 / 抽象几何？（决定你要不要画家具）
   - 字幕：原 MV 有没有歌词字幕？位置在哪？（决定了你要不要做字幕）
6. **记运镜**：每镜是推、移、还是静止。原 MV 的节奏就是观众的预期，别反着来。

### 只有歌词（没有 MV）

跳过 1–2，直接做 3 件事：
- 用音频内嵌封面抽主色（取占比最高的 3–6 个，再映射成色板），无彩度就选预设；
- 按 0.5s 窗 RMS 能量给段落定结构（判据见 engine-spec §8）；
- 从歌词里找**一个可拍的空间**（房间 / 街 / 天台 / 海边），全片尽量不换场地——低成本叙事的唯一解。

---

## 二、写剧本：五幕 + 一句话

### 先回答三个问题

1. **这首歌在说什么？**（不是歌词字面，是比喻层。例：IMAWANOKIWA = 临终之际，却写成情歌 → 拍"一个人在自己房间里等光"）
2. **谁在看？**（一个具体的人，一个空间，一个时间段。不要"一个抽象的灵魂"）
3. **最后发生什么？**（结尾必须是一个动作或一个状态变化，不是"画面淡出"）

### 五幕骨架（可改，但要有"变"）

| 幕 | 作用 | 时长占比 | 画面语言 |
|---|---|---|---|
| 一 | 建立日常 | 20% | 空间全景 + 一个重复动作 |
| 二 | 异常出现 | 20% | 多一个东西（人/光/声音），先不给解释 |
| 三 | 失衡 | 25% | 空间开始不对（倾斜/失重/物件消失） |
| 四 | 抉择 | 20% | 一个具体的动作（伸手/关灯/走出去） |
| 五 | 收束 | 15% | 回到第一幕的空间，但少了一个东西 |

每幕写一句 **intent**（这一幕要让观众知道什么），这句会直接变成 script.json 的 `intent`。
剧本正文控制在 800 字内——超过就说明你在写小说，不是 MV。

### 歌词 → 画面（强制规则）

- **一句歌词至少一个具体画面**，不许"人物站着 + 字幕"。
- 画面要能一句话说清：`她贴到窗边，玻璃上有雨` 可以；`情绪流动` 不行。
- 同义句（副歌重复）可以复用画面，但必须换景别或换色场，否则观众立刻发现你在省事。
- 抽象句（"时光是琥珀"）用**物件**接：琥珀→沙漏→胶卷，选一个，全片只用这一个。

## 三、剧本 → 分镜（script.json）

一个镜头一条，字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `t0` / `t1` | ✓ | 秒。边界对齐 LRC 行标；单镜 3–8s（副歌可 2.5s） |
| `act` | ✓ | 属于第几幕（0 起） |
| `shot` | ✓ | `scenes.REGISTRY` 里的名字，或你注册的自定义镜头 |
| `desc` | ✓ | 一句话：这一镜观众看到什么。**空着就是"站桩配词"** |
| `lyric` | | 这一镜压的那句歌词（用于核对） |
| `motion` | | 运动方式（推/移/呼吸/光移），写不出就是这镜会停住 |
| `trans` | | 进场转场。**留空最省事**：默认 `--trans smart` 只在换幕/换色场时上转场，幕内镜头一律硬切。写名字=强制该种，写 `"cut"`=这一刀硬切 |

幕用 `acts` 写，每幕一个 `field`：

- `paper` = 白场（现实）
- `accent` = 强调色场（幻想 / 药 / 亲密）
- `ink` = 黑场（闭眼之后）

色场决定这一段用哪类镜头。**白场段只放房间型（room/window/bed/door/walk/object），
强调色场只放色场型（figure/crowd/fall/halo/whiteout），黑场放（sky/corridor/title）。**
混着放，观众会觉得"剪错了"。

## 四、校验（不通过不要渲）

写完后自己按下面 8 条过一遍（实现方式随意，程序化或人工逐条核对都行）。
前 5 条是硬错误，必须清零；后 3 条是警告，逐条确认是否是有意的。

| 检查 | 判据 |
|---|---|
| 空洞 | 相邻镜之间 gap > 0.2s |
| 重叠 | 后镜起点早于前镜终点 0.2s 以上 |
| 没铺满 | 最后一镜结束 < 音频时长 −0.3s |
| act 越界 | 引用了不存在的幕 |
| 歌词无画 | 某句歌词的时间点不在任何镜头里 |
| 同镜连用 | 相邻两镜同一个 shot |
| 转场密度 | 切点 ≥12 却 0 个转场，或转场数 > 切点数的 60% |
| 色场冲突 | 白场幕里放了强调色场镜头 |

校验通过再进渲染。**校验必须挡在渲染前面**——否则会出现"渲了 5 分钟才发现少 3 秒没有画面"。

## 五、写完剧本的自问（四条，缺一条就重写）

1. 这个剧本**只能属于这首歌**吗？换一首歌还成立 → 太泛。
2. 有没有一个**只出现 2–3 次的小物件**？（信物不必是模板，但要有）
3. 结尾和开头**差在哪**？空间还在，但少了什么 / 多了什么。
4. 有没有一个镜头是**你自己想看的**？（一个都挑不出来，说明你在填表）

## 七、转场：默认不用

像素风的切换**本来就该是硬的**。转场只在两种情况下加：

1. **换幕 / 换色场**（白场→品红场、现实→闭眼）——观众需要"过一下"。
2. **时间跳跃或空间跳跃**（换场地、跳年份）——转场是"我们换地方了"的标点。

同一幕内的镜头切换、对话式正反打、情绪连续推近，**一律硬切**。
连续三个以上切点都加转场，节奏就散了——这是最常见的过度设计。

```
--trans smart   # 默认：只在换幕/换色场处上转场
--trans off     # 全硬切（更脆，很多片这样就对）
--trans all     # 每个切点都转（只用来试效果）
```

单镜要例外就在 `script.json` 里写 `trans`：`"iris"` 强制，`"cut"` 硬切。
