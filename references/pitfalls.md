# 像素 MV 踩坑总表

来自 9 个实战项目的沉淀（Vocaloid 曲、J-pop、华语流行、乐队动画、游戏宣传曲、独立电子）。
每条都是**先做错、再改对**的记录，
按"症状 → 根因 → 正确做法"写。做新歌时先扫一遍，能省掉 80% 的返工。

---

## 一、尺寸与缩放

| 症状 | 根因 | 正确做法 |
|---|---|---|
| 全片发糊、像被水洗过 | 逻辑分辨率到 1080p 用了非整数倍（如 480→1146） | 只选 480(×4) / 640(×3) / 960(×2)；NEAREST 一次到位 |
| 放大后边缘有半透明毛边 | 用了 BILINEAR/LANCZOS 放大 | 放大只允许 `Image.NEAREST` |
| 换了画布尺寸就崩（尺寸不匹配） | 尺寸被写死成常量，其他模块引用时拿到了旧值 | 尺寸只保留一处来源，绘制时现取；换画布（如做封面）要连坐标网格一起重算 |
| 16:10 封面被拉变形 | 直接把 16:9 帧拉伸 | 原生长宽比单独绘制（382×239 → ×3 = 1146×717） |

## 二、颜色

| 症状 | 根因 | 正确做法 |
|---|---|---|
| 画面出现青/黄脏色、颜色块 | `uint8` 运算溢出/下溢（多为 `flash(k>1)`、`a*(1-k)` 变负） | 所有 mix 系数 `np.clip(0,1)`；`flash` 内部先夹紧 |
| 同一帧颜色错位成条纹 | `Image.fromarray(非连续切片)` 按原 stride 读内存 | 切片后 `np.ascontiguousarray()` |
| 白场里看不出人 | 白底白剪影 | 白场用**线稿**（1px 深色）+ 品红/黑剪影，不要白剪影 |
| 全片像褪色 | 强调色饱和度不足（从封面抽色常抽到浅粉） | 抽色后校验 `max-min < 55` 就换预设强调色；三色纪律：主色 + 强调色 + 黑 |
| 大面积纯色发闷 | 想加"质感"就撒逐像素噪点 | 禁止 grain；要质感用 4×4 有序抖动（Bayer）或 1px 硬边 |
| 渐变出现色带 | 逐行线性插值 | 量化成 4–6 阶 + Bayer 抖动过渡（`vgrad`） |
| 光晕变"涟漪环"、像水波 | 用多个同心椭圆叠加造柔光 | 用 numpy 算径向衰减 `(1-d)²`，一次成图（`glow`） |

## 三、人物

> 2026-10 起默认改用**方块小人**（见 visual-spec §3）。下面几条是"拟真比例"时代踩的坑——
> 只有你仍坚持画写实人物时才需要看；否则直接上方块小人，这一整类问题都不存在。

| 症状 | 根因 | 正确做法 |
|---|---|---|
| 头比肩宽、像套娃 | 把"8.4"当像素半径用 | 立"1 单位 = h/76"（站）/ h/60（坐）；所有部件乘单位 |
| 人物怎么调都"生草" | 用拟真比例（1 单位 = 身高/76）+ 曲线拼人，放大后像橡皮泥 | 直接换方块小人：块尺寸 u、总高 21u（头 10/身 6/腿 5）、5 档色、眼睛 3×4 |
| 方块小人糊成一坨 | 给每个部件加内部描边 | 只加 1px **外**描边；部件靠颜色差分开（袖比衣暗一档、裤灰、鞋黑） |
| 方块耳朵 | 头发用矩形发片 | 用锥形发束（cap 或 taper） |
| 平头顶/"锅盖" | 头顶是常数行起笔，或直接用后发椭圆上缘 | 头顶 = 分束轮廓（多峰 + 谷）+ 弯曲贝塞尔发缝 + 发旋旋涡；后发椭圆必须低于分束谷 |
| 刘海像百叶窗 | 刘海按列平铺 | 5–6 束各自下垂量 + 斜切发梢 |
| 脸上深色太多像"伤" | 眉/眼/唇之外还加深色阴影 | 脸上深色最多三处；皮肤暗部转中性色（转红=伤，转黄=胡茬） |
| 脖子太长/悬空 | 用拉长脖子解决"露缝" | 把头放低，别拉脖子；衣服画在皮肤之上，不要在衣服上挖洞 |
| 眼睛斗鸡/像瞪人 | 眼距过窄、虹膜过大、圆形眼 | 柳叶眼（宽高比 ≥2），虹膜 50–88%，高光 1px 方块 |
| 2px 宽的脸五官糊成一团 | 五官用了小数坐标 | 脸/眼/眉必须落在整数行/列 |
| 手部特写像土豆插蜡烛 | 手搓椭圆拼手指 | 复用已验证的 `hand()/fist()`；手指细节 ≥5px，否则被描边吞掉 |
| 大特写"诡异" | 正面完全对称 + 程序化脸 | **不做大特写**。要情绪用中景/剪影；3/4 侧转是底线 |
| 程序化角色永远差一口气 | 几何原语组合没有圆柱受光、无衣褶 | 承认上限：远景用剪影+边缘光，近景才上细节；不要靠"继续改比例" |

## 四、翅膀 / 道具 / 动物

| 症状 | 根因 | 正确做法 |
|---|---|---|
| 翅膀像纸片/齿轮 | 单个多边形；或锯齿后缘 | 翼形整体 polygon + 三排覆羽 `arc(8..172)` + 前缘覆羽带 |
| 蝶翅像两个圆 | 椭圆拼 | 扫描线填充的 12 点轮廓 + 三层内缩 + 翅脉 |
| 孔雀像蒲公英/折扇 | 羽轴太细、眼斑半径随 r 线性放大 | 实体羽瓣（内外弧多边形）+ 眼斑固定 4–5px 贴羽尖 |
| 乌鸦/蝙蝠像蝠鲼 | 正面对称双翼 | 改侧视：头 + 楔形喙 + 扇形尾 + 一上一下双翼 |
| 爆炸像靶心/唱片 | 同心圆 + 亮核 | 多个偏移椭圆做不规则外缘；火球挖空核心再叠白 |
| 火墙像一排蜡烛 | 等距火柱不重叠 | 柱间距 < 直径，让柱间交叠 |
| 云像"圆盘光" | 单个大椭圆 | 3–5 个不同半径椭圆并集，再整体受光 |
| 剪影比背景亮、读不出 | 剪影与背景同亮度 | 剪影必须比背景暗一档以上 |

## 五、镜头与运动

| 症状 | 根因 | 正确做法 |
|---|---|---|
| 有的镜头"停住" | 只有静态构图 | 每镜必须有推/移/漂移；完工后用 0.2s 帧差审计，<0.25% 视为停住 |
| 平移后像素糊 | 用 resize 做位移 | 位移一律 `np.roll`（像素精确） |
| 拉远时满屏色块/崩 | `cam(z<1)` 裁剪窗口大于画面，`clip` 后 lo>hi | 缩放只允许 `z≥1`；要"拉远"就画小 + 后期压白 |
| 地板透视线像裂纹 | 480 宽下画收敛线 | 只留视平线 + 投影 |
| 镜头间像同一张图 | 候选池太小、只保证"不与上一镜相同" | 段内轮转用完所有候选；同镜第 k 次出现做镜像 / 1.035 倍缩放 |
| 全片色场混乱 | 白场/品红场镜头混在同一段 | 按段落固定色场，同类镜头成组（白场只放房间型） |
| 全片都在品红场 | 用"歌词重复"判副歌 | 用音频 RMS 能量分段：段均值 > 中位数×1.12 才是副歌 |

## 六、光与后期

| 症状 | 根因 | 正确做法 |
|---|---|---|
| 大范围补光有硬边 | `blend_rect` 区域混合 | 大面积用 `glow` 径向；小面积才用矩形 |
| 整块背景被压暗成黑方块 | alpha 按矩形区域混合 | 存快照 → 画 → `before*(1-α)+after*α`，只对真画过的像素生效 |
| 冲击帧刺眼、节奏被打断 | 整段填纯色 | 入场白闪 + 内容；`k` 控制在 0.35 以下，只在关键拍用 |
| 画面露底/横带 | 场景没铺满画布 | 每帧先整幅铺底色，再画元素 |

## 七、字幕与文字

| 症状 | 根因 | 正确做法 |
|---|---|---|
| 中文糊成一团 | 480 宽下字号 <12px | 字幕在**放大后的层**用真字体（jp 40 / cn 30）；画面内文字 ≥13px |
| 白场白字看不见 | 字色固定白 | 字色跟色场：白场品红、品红场白、黑场品红/亮色 |
| 底板像黑杠、还切人 | 半透明通栏底 | 无底框 + 2px 描边（这是本项目统一的字幕语言） |
| 8 向描边把汉字糊死 | 描边过粗 | 2px 硬描边即可，别做发光描边 |
| 字被调色洗淡 | 字幕画在 grade 之前 | 字幕永远最后叠 |
| LRC 的"歌：xxx"飘在画面上 | 未过滤制作人员行 | 解析时剔除 `^(歌|作詞|作曲|編曲|曲|詞)\s*[：:]` |
| 字幕与人物抢位置 | 底边距太小 | 距底 150px（1080p），居中；镜头构图时预留底部 1/6 |

## 八、音频 / 歌词

| 症状 | 根因 | 正确做法 |
|---|---|---|
| 时长读不到 | 环境里没有 ffprobe | 回退解析 `ffmpeg -i` 的 `Duration:` |
| BPM 报成 23.7 | 取全局最大自相关=小节周期 | 取第一个显著局部峰（>0.35），再折叠到 70–180 |
| 分段全错 | 靠歌词重复/靠固定秒数 | 用 RMS 能量包络（0.5s 窗）+ 歌词停顿 |
| 歌词与画面差半拍 | LRC 行标是"开始唱"，画面却在整秒切换 | 镜头边界吸附到 LRC 行标；字幕提前 0.15s 入 |
| 音源被版权识别 | 直接用原曲 | 简介首行写清二创与版权归属；被静音就换平台已授权音源，画面不动 |

## 九、代码与工具

| 症状 | 根因 | 正确做法 |
|---|---|---|
| `str.replace` 改了 6 轮没生效 | old 串差一个字符就静默跳过 | 改完必须 grep 验证；长改动按行号整段替换 |
| 批量 replace 互相串改 | 前一条的结果被后一条再匹配 | 一次一条 + `count=1` + 立即验证 |
| 渲染 4 分钟白跑，最后崩 | 镜头函数签名不统一 | `frame()` 用 `inspect` 过滤 kwargs；先渲染 30 秒预览 |
| 内存/速度炸 | `np.correlate` O(n²) 未降采样 | 先降到 8kHz；mask 用 bbox 局部画布 |
| 后台管道缓冲 | stdout 被块缓冲 | rawvideo 直写 stdin，日志 `flush=True` |

## 十、叙事与分镜（最贵的一类）

| 症状 | 根因 | 正确做法 |
|---|---|---|
| "这镜头在干嘛" | 只有抽象图形，没有上下文 | 每个镜头必须有可命名的场景（房间/门/窗/桌面）；补上下文而不是加特效 |
| 全片像 PPT | 每镜 8 秒以上、无运动 | 单镜 3–8 秒；长镜必须有内部运动（呼吸/推近/光移） |
| 素材复用太多 | 每段只用 3–4 个镜头 | 每段 5–7 个候选；不够就加新镜头，而不是重复用 |
| 情绪跟不上歌词 | 分镜按"好看"排，不按歌词 | 逐句对齐：一句一镜或两镜；副歌才允许碎切 |
| 结尾泄气 | 最后一个镜头仍是中景 | 收尾要"收"：拉远 / 光吞 / 黑场 + 一个静止小物 |

## 十一、转场与叙事（2026-10 补）

| 症状 | 根因 | 正确做法 |
|---|---|---|
| iris 转场变成一颗"鸡蛋" | 归一化用了不同分母（x/W, y/H），等值线不是圆 | 用像素欧氏距离除同一个尺度，才得到正圆 |
| 转场像电视雪花 | 溶解用逐像素随机 | 用 2×2 块噪声；像素溶解要有"块" |
| 同一命令两次渲染画面不同 | 用了内置 `hash()`（带 PYTHONHASHSEED） | 用 `zlib.crc32` 等稳定哈希做种子 |
| 转场把节奏打散 | 每个切点都上花式转场（"转场库"最容易犯） | 默认全硬切，只在换幕/换色场处加；副歌短(0.35s)、抒情长(0.6s)；同种不连用 |
| 走路镜头裙摆里多出黑块（像三条腿） | `figure_stand` 已画腿，又手搓两条交替腿叠加 | 长裙角色不画迈步，用整体"上下一格"起伏 + 裙摆抖动代替 |
| 转场后画面"跳"一下 | 入点冻结了下一镜的首帧 | 冻结**上一镜的末帧**淡出，让下一镜正常走 |
| 全片"太顺"，没有游戏感 | 角色和镜头都满帧 | 角色动作 8–12fps 步进，镜头满帧，错位才是复古 |
| 白场段里插入品红镜头，观众觉得剪错 | 同段混色场 | 白场只放房间型，强调色场只放色场型；校验器会报 |
| 一句歌词只有人物站着 | 分镜记成"情绪流动" | 一句一个具体画面；`desc` 必须能被外人一眼看懂 |
