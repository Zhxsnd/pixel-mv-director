# 引擎规格（语言无关，照此可从零实现）

这份文件不含任何语言代码。任何能读写文件、能画位图、能调 ffmpeg 的 agent，
按这里的契约实现一遍，就能产出与本 skill 一致的成片。

---

## 1. 输入 / 输出

**输入**：音频文件、LRC 歌词、剧本分镜 `script.json`（结构见 `narrative.md` §三）。
**输出**：`1920×1080 / 24fps / H.264 + AAC` 的 mp4，时长 = 音频时长（误差 < 0.1s）。

---

## 2. 画布与缩放

| 项 | 值 |
|---|---|
| 逻辑画布 | 480×270（默认）/ 640×360 / 960×540 |
| 放大倍数 | `1920 / 逻辑宽`，必须是**整数** |
| 缩放算法 | 最近邻（NEAREST / `image-rendering: pixelated`），任何插值都禁止 |
| 帧率 | 24 fps（镜头）；角色动作另按 12 fps 量化 |

绘制时只允许整数像素落点。斜线用逐点画（阶梯），不许抗锯齿。

---

## 3. 颜色

调色板是 7 个具名字段，所有绘制只从这里取色：

| 字段 | 含义 | 典型 |
|---|---|---|
| `paper` | 主亮色（白场墙、纸） | `#FFFFFF` |
| `ink` | 主暗色（剪影、字） | `#000000` |
| `accent` | 强调色（唯一高饱和） | `#FF1D6F` |
| `accent_d` | 强调色压暗（地面、暗部） | accent × 0.72 |
| `mid` | 次亮色（玻璃、墙裙） | paper × 0.90 |
| `glow` | 强调色提亮（光晕、高光） | accent 提亮 |
| `ink2` | 次暗色（黑场底、深表面） | ink × 1.55 |

规则：
- 全片只有一个强调色。出现第二个高饱和色就是错。
- 抽色来源：原 MV 逐帧 > 官方曲绘 > 音频内嵌封面。
- 抽色后必须校验：最深色亮度 < 90，否则压到近黑；最饱和色 `max-min < 55` 视为无彩度，改用预设强调色。
- 提亮用 `c + (255-c)·k`，不要用 `c·k`（浅色会爆白）。

---

## 4. 绘制原语（契约）

所有原语都直接改逻辑画布数组/位图，**越界必须钳制**（负坐标不能变成"从末尾切片"）。

| 原语 | 行为 | 陷阱 |
|---|---|---|
| `blank(c)` | 整幅填色 | 每帧先铺满，否则露底 |
| `px(x,y,c)` | 单像素，越界忽略 | 坐标取整 |
| `rect(x0,y0,x1,y1,c)` | 实心矩形，坐标先排序再钳制 | x1<x0 或 y1<y0 时不许反向切片 |
| `line(p0,p1,c,w)` | 逐点画（步数 = 长边像素数） | 不许用 GPU 抗锯齿线 |
| `ellipse(cx,cy,rx,ry,c)` / `ring` | 实心 / 环（外减内） | 环必须用"外椭圆减内椭圆" |
| `poly(pts,c)` | 多边形填充（扫描线或系统多边形填充） | 点序任意，但要闭合 |
| `cap(p0,p1,r0,r1)` | 锥形胶囊：沿线插值半径的圆并集 | 肢体专用；矩形拼四肢必出方块 |
| `glow(cx,cy,r,c,strength,ry?)` | 径向衰减：`f=(1-d)²·strength`，`out=a·(1-f)+c·f` | 用多个同心椭圆叠加会出"涟漪环" |
| `vgrad(y0,y1,c0,c1,steps)` | 量化渐变 + 4×4 Bayer 抖动过渡 | 逐行插值会出现色带 |
| `dashes(y,x0,x1,c,on,off)` | 虚线 | 低分辨率下别太密 |
| `shadow(cx,fy,w)` | 椭圆投影，把该区域亮度乘 0.86 | 只压暗，不涂色 |

所有颜色混合的系数必须先钳到 `[0,1]`：`k>1` 会让 `a·(1-k)` 变负、8 位无符号回绕成青/黄脏色。

## 5. 人物

坐标表见 `visual-spec.md` §3。要点：
- 站姿 1 单位 = 身高/76；坐姿 = 身高/60。
- 剪影 + 边缘光：把整个人形遮罩向左上偏移 1px 涂亮色，再压主体暗色。
- 长裙角色不画迈步（腿会被裙摆吞掉），用整体"上下一格"起伏表示走。
- 不做脸部大特写。

---

## 6. 镜头接口

每个镜头是一个纯函数：

```
shot(frame, t_local, dur, palette, rng) -> frame
```

- `t_local` 是镜头内时间（0..dur），`p = t_local/dur`。
- **必须自带运动**：推近 / 平移 / 呼吸 / 光移，至少一种。
- 不许依赖上一帧状态（纯函数），否则并行渲染会闪。
- 随机数必须由 `(镜头名, 第几次出现)` 决定，不能用系统随机或运行期 hash。

内置 15 个（可按需增删）：room / window / bed / door / walk / object / corridor / sky / crowd / figure / fall / halo / whiteout / title。

镜头按色场分组：

| 色场 | 可用镜头 |
|---|---|
| `paper` 白场 | room, window, bed, door, walk, object |
| `accent` 强调色场 | figure, crowd, fall, halo, whiteout |
| `ink` 黑场 | sky, corridor, title, object |

同一段内不许混色场。

---

## 7. 转场（8 种，全部是像素 mask 换场）

`transition(a, b, k, kind) -> frame`，`k∈[0,1]`。默认实现就是"按 mask 取 b 或 a"。

| kind | mask 定义 |
|---|---|
| dissolve | 2×2 块平均噪声 `< k`（逐像素噪声像电视雪花，要块） |
| checker | `(x//8 + y//8) / (W/8 + H/8) < k`（对角铺开） |
| blinds | `x % 10 < k·10`（竖向百叶） |
| iris | `dist((x,y),center) / (0.62·W) < k·1.08`（必须像素等距，否则变鸡蛋）；边缘可描 1–2px 强调色 |
| wipe | `x + (y - H/2)·0.25 < k·(W + H·0.25)`（斜边横扫） |
| glitch | 50% 噪声混合 + 一条高度 `k·H` 的横带位移（位移量随 k 变） |
| ripple | `sin(d·9 - k·9)·0.5 + d < k`（同心波） |
| mosaic | 两帧各自块化（块边长 `1+12(1-k)`）后按噪声混合 |

**择优使用**（默认策略 `smart`）：

1. 换幕 / 换色场 → 必用。
2. 幕内：距上一个转场 ≥3 个切点，且该镜时长 ≥3.5s → 才考虑。
3. 全片转场数 ≤ 切点数 × 0.34。
4. 最近两个用过的种类不再用（防"隔一个重复"）。
5. 第一个镜头不转场。
6. 时长：副歌 0.35s、抒情 0.6s、尾声 0.7s。
7. 实现细节：**冻结上一镜的最后一帧**淡出，让下一镜正常播放（冻结入点会让人误以为卡住）。

`off` = 全硬切；`all` = 每个切点都转（只用来试效果）。单镜可用 `trans` 字段强制或写 `"cut"` 取消。

## 8. 编排（没有手写分镜时）

1. 时长：读音频容器时长。
2. 能量：0.5s 窗 RMS，归一化到 0..1。
3. 分段：歌词间隔 > 4s 处切；段均值 > 全片中位数 × 1.12 判副歌；< 0.78 判间奏。
4. 每段镜头数 = 段长 / 6.5s（向上取整），段内按镜头池轮转（先用完所有候选再重复）。
5. 同镜第 k 次出现：k 为奇数镜像，k%3 非零时中心放大 1.035。
6. 转场按 §7 的择优规则。
7. 色场：按段落的能量标签映射（verse→paper、chorus→accent、break→ink）。

## 9. 字幕

| 项 | 值 |
|---|---|
| 位置 | 水平居中，底边距 150px（1080p） |
| 日文 | 40px（msgothic / 系统等宽日文字体） |
| 中文 | 30px（微软雅黑 / 系统黑体），日文下方 +12px |
| 描边 | 2px，颜色 = `ink` |
| 底色 | 无 |
| 字色 | 白场用 accent、强调色场用 paper、黑场用 accent |
| 时机 | 从该句时间码起，取 `min(下一句, +3.6s)` |
| 绘制层 | 在**放大后的成片层**画（逻辑层画中文会糊），在所有调色之后 |

LRC 里 `歌：/作詞：/作曲：/編曲：` 开头的行不是歌词，必须过滤。

## 10. 渲染

逐帧编码，不要把帧落盘再编码（慢一个数量级）：

```
帧循环:  算出 1920×1080 的 RGB 原始字节 → 写入 ffmpeg 的 stdin
命令:    ffmpeg -f rawvideo -pix_fmt rgb24 -s 1920x1080 -r 24 -i - \
                -i audio -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p \
                -c:a aac -b:a 192k -shortest out.mp4
```

参考量级：480×270 逻辑、6076 帧（4:13），含编码约 3–4 分钟。

---

## 11. 审计（渲完必须跑）

1. **停住检测**：对每个镜头取 `t` 与 `t+0.2s` 两帧，灰度差 > 8 的像素占比。**< 0.25% 判停住**
   （标题卡豁免，有意静止）。停住的镜头必须补运动。
2. **脏色扫描**：统计 `(r>200,g>140,b<120)`（黄）与 `(b>180,g>140,r<120)`（青）的像素占比，
   任一 > 0.2% 说明有 8 位回绕导致的脏色，去查 `k>1` 的混合系数与非连续切片。
3. **时长对齐**：成片时长与音频差 < 0.1s。
4. **镜头重复**：同一镜头全片 ≤6 次，且不毗邻。

## 12. 验收清单

- [ ] 像素块大小全片一致，无半像素模糊
- [ ] 全片只有一个强调色，色场不混段
- [ ] 每句歌词都有具体画面（不是"人物站立 + 字幕"）
- [ ] 停住镜头 0 个
- [ ] 转场数 ≤ 切点 34%，且都落在换幕/跳时空处
- [ ] 字幕不压人物、不压关键动作，白场用 accent 字
- [ ] 时长 = 音频时长，片子首尾都有画面
- [ ] 封面 1146×717，缩到 160px 宽仍能读出"人 + 形状 + 字"
