# B 站发布包模板

## 标题（≤80 字，三选）

| 类型 | 公式 | 例 |
|---|---|---|
| A 推荐 | `【原作/角色】曲名（原文副题）形式｜一句钩子` | `【初音ミク】IMAWANOKIWA（いまわの際）全曲像素MV｜临终之际，光环是什么形状` |
| B 形式向 | `用什么手法重画《曲名》｜作者 形式 时长` | `用三种颜色重画《IMAWANOKIWA》｜初音ミク 全曲像素MV 4:13` |
| C 保守 | `【形式】曲名 / 作者 feat.角色【全曲】` | `【像素MV】IMAWANOKIWA / いよわ feat.初音ミク【全曲手绘逐帧】` |

- 曲名的**原文写法**必须保留（大小写、假名），搜索靠它。
- 钩子用一句歌词的疑问式改写，不要用"震撼""神仙"这种词。

## 简介骨架

```
<一句钩子：把歌名的意思翻出来>

<一句制作说明：画布尺寸 / 颜色数 / 帧数 / 有没有贴图>

■ 原作
曲　：<作者>「<曲名>」feat.<歌手>（<年份>）
原 PV：<作者>
本作为非官方二次创作。音乐、角色、原企划版权归原作者所有；
像素画面、分镜与中文字幕为本人自制，请勿搬运或商用。

■ 制作
画布 480×270 → 成片 1920×1080 / 24fps
色板只有三个：<主色> / <强调色> / <黑>（对着原 MV 逐帧吸的色）
人物、场景全部用几何体在代码里现画，无贴图
字幕：原文 + 自制中译，无底框

■ 章节
00:00 一 · <幕名>
00:53 二 · <幕名>
...

■ 一点想法
<2–4 行，说说这首歌唱的是什么，你是怎么理解的。不要复述剧情。>

■ 同系列
<前作 1 / 前作 2>，都在主页
```

## 章节

B 站支持简介里写 `mm:ss 标题` 自动生成章节。规则：
- ≥3 个时间点才生效，第一行建议 00:00。
- 用"幕"而不是"第X段"，与剧本一致。
- 每个时间点对齐一个真实的剪辑点（镜头切换处）。

## 标签（9 个以内）

```
<角色/歌手> <曲名> <作者> 像素 MV VOCALOID 二创 手书 原创PV
```
前三个是搜索词，后面是推荐池。

## 投稿设置

| 项 | 值 |
|---|---|
| 分区 | 音乐 → VOCALOID·UTAU（器乐/乐队曲用 音乐 → 原创音乐 或 翻唱） |
| 类型 | 自制（简介首屏必须写明二创性质） |
| 封面 | 1146×717（16:10），≤5MB |
| 字幕 | 已内嵌，无需上传 CC |
| 转载 | 不要勾"转载"，但简介要写清原作 |

## 版权风险

用了原曲音频，可能被识别：

1. 简介最上方加一行 `本视频为二次创作，音乐版权归 <作者> 所有`
2. 仍被静音 → 换平台已授权的音源，画面不动，只换音轨：
   ```
   ffmpeg -i MV_auto.mp4 -i 新音源.flac -map 0:v -map 1:a -c:v copy -c:a aac -shortest out.mp4
   ```
3. 不要为了"躲识别"去变调/加噪 —— 会毁掉混音。

## 置顶评论

补一条"读法"，比在简介里堆字有效：

```
补充：<曲名> 是 <词源/双关>，意思是 <一句话>。
所以全片没有 <你刻意没做的东西>——<为什么>。
```

## 封面要点

- 元素 ≤4：一个大形状 + 一个剪影 + 一行大字 + 一个小标签。
- 大字在放大层渲染，3px 深色描边。
- 缩到 160px 宽还能读出"人 + 形状 + 字"才算过。
- 不要在封面上写"高清""完整版"这类词，点进来就知道。
